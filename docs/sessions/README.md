# Claude Code session logs

Save a short Markdown log for each Claude Code session as `docs/sessions/YYYY-MM-DD-<topic>.md`.

Each log should record:

- **Goal** — what the session set out to do.
- **Prompts used** — the key prompts that guided the work.
- **What changed** — files or behavior changed.
- **Test results** — commands run and their outcomes, or why tests were not run.
- **Problems** — blockers, unexpected behavior, or unresolved questions.
